Instant-render contract

Validate once. Normalize once. Render everywhere.

The domain schema protects correctness; the compact result envelope removes presentation ambiguity. The Run page owns every reusable visual and action.

1
Validate the skill output
The completed raw result must satisfy its versioned `output_schema`.
2
Project the display envelope
Worker assigns type, kind, MIME, safe artifact URLs, names, and sizes.
3
Resolve the prebuilt view
Registry renders preview, actions, mobile layout, and raw fallback.
