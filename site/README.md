# Cognition storefront (launch-ready)

Single-file static storefront for cognition.cv — brand, 3 real packages, live UGC demo box, waitlist form. Built with vanilla HTML/CSS/JS; no build step, works from `file://` and on Cloudflare Pages.

Open it: just open `site/index.html` in a browser (double-click it, or run `python3 -m http.server` from the repo root and visit `/site/`).

Contents: hero + search + filter chips, 3 real listings (UGC Script Studio, Meta Ads API Analyser, Product Photo Generator), detail dialog with INPUT→OUTPUT examples, price tiers, three use-doors, and a live demo that posts to the Cognition demo worker.
