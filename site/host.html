    Quick answers

    Before you upload.

    If your workflow can be described in markdown, it has a home here.

    What formats work?

    A .md file up to 200 KB with one-line name and description values in YAML frontmatter. Every valid file can enter review; only an approved runtime profile can advance to deployment.

    How much does it cost?

    You pay per run — usually cents to a few dollars, auto-priced from real costs. Every new account gets free credits to start.

    Can I keep it private?

    Not yet. This first version accepts public marketplace workflows while owner-only routing is built.

    What about listing publicly?

    List your workflow in the Omo marketplace and keep 85% of every run.
