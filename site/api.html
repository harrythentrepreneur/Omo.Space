Call any helper

Send a POST to the run endpoint with the helper's slug and its inputs. You'll get a run_id back, then poll for the result.

Base URL

# Base URL — every helper lives here
const BASE = "https://api.omo.space";

1 · Start a run

curl -X POST "https://api.omo.space/v1/runs" \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"slug": "arcads-node-ugc-builder", "inputs": {"product_description": "Silk pillowcase set"}}'

Response: {"run_id": "run_1ab2", "status": "accepted"}

2 · Poll for the result

curl "https://api.omo.space/v1/runs/run_1ab2" \
  -H "Authorization: Bearer YOUR_KEY"

Response: {"status": "completed", "result": {...}, "usage": {"cost_usd": 1.40}}

Endpoints

POST/v1/runsStart a helper run — returns run_id
GET/v1/runs/{run_id}Poll a run — running or completed
GET/api/meYour balance, key, and recent usage
POST/api/topupTop up credits (Stripe Checkout)

Billing

Every new account starts with $5 of free credits. Each run debits your balance at the helper's per-use price (shown on its card, e.g. run ≈ $1.4). When your balance runs low, top up from $5 or choose $20, $50, $100, or $200 on the dashboard.

You only pay for runs that start. Failed validations cost nothing.
