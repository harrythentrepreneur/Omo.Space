What is MCP?

MCP is a simple bridge between your AI assistant and useful tools. It lets Claude, Codex, Cursor, and other compatible assistants ask Omo what helpers are available and run them for you. You stay in the conversation; Omo handles the catalogue, workflow, and clear per-run billing behind the scenes.

Five useful tools

What your assistant can do

The names are plain on purpose. Your assistant chooses them automatically, or you can ask for one directly.

ToolWhat it does
omo_search_helpersSearch the catalogue by job, category, or niche and compare own and per-run prices.
omo_get_helperShow one helper’s full description, required inputs, outputs, and workflow summary.
omo_run_helperRun a helper with your inputs and optional Omo API key, then return the result and credit cost.
omo_get_balanceCheck your current Omo credits and recent helper usage.
omo_topup_optionsShow top-up choices and point you to secure Stripe checkout on the Omo dashboard.

Two-minute setup

Connect your assistant

Omo speaks Streamable HTTP at https://omo.space/mcp. No local server or package install is needed.

Claude Desktop · claude_desktop_config.json 
{
  "mcpServers": {
    "omo": {
      "type": "http",
      "url": "https://omo.space/mcp"
    }
  }
}
Codex

Add a remote MCP server named omo with the URL https://omo.space/mcp, then ask it to list Omo helpers.

Cursor

Open MCP settings, choose a remote HTTP server, and use the same name and URL. Tool discovery happens automatically.

Any MCP client

Use Streamable HTTP, send JSON-RPC 2.0, and start with initialize followed by tools/list.

Before the first real run

Get an API key

Browsing the catalogue is open. An API key connects paid runs and balance checks to your Omo credits.

Open the API page

Sign in at omo.space/api.html to reveal your personal omo_ key.

Keep it private

Give it only to the api_key field when your assistant calls omo_run_helper.

Ask naturally

Try: “Find a product-video helper, show me the price, then ask before you run it.”

Clear per-run pricing

Each helper shows its run price before work starts. Successful keyed runs debit that amount from your Omo credits. Top-ups happen securely through Stripe on the dashboard; MCP never takes payments in v1.
