# Omo GTM strategy (decided)

## Channels (in priority order)
1. Earned content — IG/TikTok reels: "how to make X for $0.30" (step 1 input -> step 2 omo.space -> step 3 result). Primary acquisition; no paid ads needed.
2. Open-source first-party workflows on GitHub (skill.md + tests + fixtures, one repo per workflow). Trust + SEO + agent-recommendation moat.
3. The 4,500-email PhonicsMaker list (initial proof + first paying cohort).
4. Creator DMs (later — after the loop works; corrected DM script only).
5. Paid ads (last — gated behind LTV/CAC + repeat + support gates).

## Wedge: Education first, then clone
Education menu first: phonics decodable book, math worksheet, worksheet, phonics song,
CVC word sheet, classroom pack. Prove 3-5 sell from reels, then clone the playbook into
UGC ads, product photos, ecom creative, analysis, etc.

## Reel template (15s)
- Hook (3s): "This book costs $0.30" / "Teachers, stop paying $20/month for one worksheet."
- Step 1 (4s): type the topic.
- Step 2 (4s): screen -> omo.space workflow card.
- Step 3 (4s): finished result + "$0.30, no subscription."
Faceless (screen-record + text + VO) vs founder-on-camera: TBD.

## Open-source + download door
- First-party workflows only. NEVER creator IP.
- Download door shows honest self-host cost (API keys + setup + ~$/mo fees) vs
  "run on Omo for $0.30 — we handle providers/billing/updates."
- Rule: honesty over manipulation. The "warning" is a transparent cost comparison,
  not a scare tactic.

## Edtech competitor hunt (systematic content + product engine)
Go down the education-SaaS enemy list (MagicSchool AI, Diffit, Eduaide, Curipod,
Twee, Brisk, SchoolAI, Quill, Canva Edu, etc.) and for each produce (a) an equivalent
first-party workflow and (b) a reel: "their $X/mo feature = $0.30 on Omo, no
subscription." Copy the OUTCOME, never their brand/design/specific outputs (IP risk +
platform bans). Teachers are the highest word-of-mouth vertical (FB groups / TikTok
teacher communities). Say "a few cents," not "free." Mix higher-price workflows
($1-3) to reach $200/day faster. $200/day ≈ 500-700 paid runs/day at $0.30-0.40
margin, or ~150-300/day with a few $1-3 tools — a compounding volume play.

## Sequence (fixed)
GATE 1 (payment loop live + canaries + 200-email proves a teacher pays twice) FIRST.
Then reels + open-source repos fire. Content into a broken checkout = burned trust.

## Unit-economics honesty
A reel is a compounding/volume play, not a per-reel printer: 100k views -> ~1% click
-> 2-3% buy -> 10-30 sales -> $2-7 margin/reel, compounding over weeks. Psychology
must survive the first 10 reels.
