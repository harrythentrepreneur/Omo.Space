# Omo Open-Source Policy (canonical)

- ALL phonics/teacher tools and skill.md files are open-sourced on GitHub under the **omo-space** organization.
- **EXCEPTION — NEVER open-source: the Phonics Book Maker** (illustrated-decodable-story-maker / the flagship book-builder). It is **PRIVATE** and its SKILL.md is sold for **$400** on the marketplace.
- Never create a public repo, or push any file, for the book maker. Keep it private, chargeable, and exclusive.
- Open-source repos get SEO-friendly names + topics (skill-md, ai-skill, phonics, education, agents) and link back to omo.space.
