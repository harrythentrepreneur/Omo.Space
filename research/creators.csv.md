## Pipeline statuses
- mined      = found on feed, qualifies, not yet rebuilt
- packaged   = workflow rebuilt as Bench package
- page_live  = sales page created from template
- dm_sent    = founder sent the DM (script in acquisition-playbook.md)
- replied    = creator responded positively
- listed     = live on Bench with their link
- rejected   = said no / ghosted after follow-up

## Notes
- Always save the reel URL — we need it to rebuild the workflow and for the DM.
- Qualify hard: business-buyable output, posts weekly, currently gives it away free.
- Never DM without a live sales page — the link IS the pitch.
