**Purpose:** Identify what EXACTLY Bench is and does, to identify desires, build
avatars, and create winning outreach — mirroring the PhonicsMaker format.

## Step 1: Basics

### Product Name: Bench
**Price Point:** License $19–$99 (launch: $29–$49) · Run credits $10/$25 ·
Maintain $5–$25/mo · Team: custom. **Creator keeps 85% of license sales
(95% creator-referred), 20% of positive hosting margin, 85/15 maintenance.**
**What it is:** The store for AI helpers — workflows, agents, prompts, skills
that ACTUALLY RUN. Creators sell what they make; buyers use it via API, on the
platform, or on their own machine.

### The One-Line
**"From 'DM me' to paid."** (creators) / **"Try it. Use it anywhere."** (buyers)

### Product Overview (what it is — 5 bullets)
1. A marketplace where AI creators list their workflows/agents/skills with a
   cover, description, INPUT→OUTPUT examples, a working demo, and a price
   (skool-style listing, gumtree analogy).
2. Bench RUNS what it sells: workflow + model hosted together in containers,
   served via API (one key) or on-platform, or handed over as files for local use.
3. Try-before-you-buy: capped free demo (5 sessions/day, hard dollar/token caps)
   so buyers see real output before paying.
4. Transparent money: published splits (85/15, 95/5, 20% hosting margin),
   "On a $100 license, you keep $85."
5. The moat: hosting + execution + remembered personal state — the un-copied
   half of the loop. Not another prompt gallery.

### The "Status" Desires (Ego, Recognition)

## Step 3: Avatar (Who we're talking to)

### Avatar A — "The DM-Me Creator" (PRIMARY)
- **Who:** 23–40, makes AI workflows for Instagram/TikTok (UGC scripts, ad
  analysers, photo tools). 2k–200k followers. Posts weekly. Says "DM me for the
  workflow" or drops a GitHub link.
- **Core desire:** Income without becoming a software company.
- **Current state:** Gives away valuable work for free; gets DMs, not dollars.
- **Trigger:** "DM me" is now a punchline; they want paid.
- **Objection:** "Is this another PromptBase? Will my work get stolen?"
- **Proof needed:** a real demo page of THEIR work with a price.

### Avatar B — "The Overwhelmed Buyer" (ecom/small biz)
- **Who:** ecom brand owner / media buyer / freelancer. Wants output, not setup.
- **Core desire:** A tool that works NOW, without a dev or a repo.
- **Current state:** Saves reels, never uses them — too much setup.
- **Trigger:** Sees the same workflow on Bench with a "Try it" box.
- **Objection:** "Is this going to eat my API credits?"
- **Proof needed:** capped free demo showing real output.

### Avatar C — "The Side-Project Seller" (r/SideProject crowd)
- **Who:** indie hacker who already sells prompts/agents, frustrated with
  PromptBase ($700/mo ceiling, silent payouts, "balance fraud").
- **Core desire:** Better economics + trust + hosting.
- **Current state:** "STOP SELLING ON PROMPTBASE" energy.
- **Trigger:** 85/15 + running demos + 20% hosting margin.
- **Objection:** "How do payouts actually work?"
- **Proof needed:** the published waterfall + a demo that runs.

## Step 4: Mechanisms / USPs (What Bench does that others don't)

1. **Runs what it sells** — hosted containers, model + workflow together. The moat.
2. **Try-live demo before buying** — capped free sessions; demo-with-cap
   protects the creator's IP.
3. **Transparent waterfall** — 85/15, 95/5, 20% hosting margin, published.
   Beats PromptBase's 80/20, and beats their trust problem ("available soon
   balance fraud").
4. **Three use-doors** — API / on-platform / local files. + remembers you.
5. **Niche-by-job discovery** — skool-style cards + upvotes/trending + verified
   runs. Anti-GPT-Store curation.
6. **Cross-framework packaging** — SKILL.md ↔ MCP ↔ n8n ↔ GPTs with honest
   native-vs-converted labels.

## Buyer-side top insights (from reddit-buyer-side.md, 8 threads)

1. Zero-setup is the killer feature — try-it box (no key, no install) is the relief buyers describe.
2. Sell outcomes, not tech — demo the OUTPUT, price the outcome, skip architecture talk.
3. Boring niches print money — document parsing, invoice extraction, form routing ($500/mo examples).
4. Cost fear is a feature if addressed — prepaid credits + "cost shown before checkout."
5. The "copy/paste between apps" buyer is underserved — form→spreadsheet, quote→invoice→calendar; each is a listing with a 2-minute demo.
