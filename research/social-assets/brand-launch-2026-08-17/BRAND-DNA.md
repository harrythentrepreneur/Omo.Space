# Omo Space brand DNA

## The brand

**Name:** Omo Space  
**Short form:** Omo  
**Site:** omo.space

**Positioning:** The marketplace for useful AI workflows.

**Core promise:** Give Omo a clear input. Get a finished result you can use and keep.

**Commercial idea:** Buy the result. Not another subscription.

Omo should feel like a warm frontier workshop for practical AI. It is not a generic AI chat product, not a loud crypto marketplace, and not a Minecraft account. The visual system should make useful work feel tangible.

## Voice

- Clear before clever.
- Warm, not childish.
- Confident, not overhyped.
- Explain the result before the technology.
- Use short sentences.
- Prefer concrete nouns: book, chart, video, document, workflow, result.

## Visual direction: Living Utility

The chosen direction is **Living Utility**: finished artifacts, small paths between steps, and a friendly orange bean mark. The system combines editorial typography with simple diagrams and soft organic shapes.

Every post should contain:

1. A cream field.
2. A pine frame or pine rule.
3. One clear Fraunces headline.
4. DM Sans for labels and supporting copy.
5. Mint, peach, or butter as supporting fields.
6. Orange as a small signal, never the whole canvas.
7. A small Omo mark or `omo.space` footer.

## Tokens

| Token | Hex | Use |

| Cream | `#F8F7F5` | Main canvas |
| Warm cream | `#F7F3E8` | Soft background variation |
| Pine | `#17352C` | Ink, frame, core text |

| Peach | `#FFB89D` | Human warmth |
| Butter | `#FFE7A3` | Highlights and small badges |
| Orange | `#FF6B3D` | Action, price, signal, bean mark |
| Muted | `#5F6F68` | Supporting text |

## Typography

- **Display:** Fraunces 800. Use for the main thought.
- **Body:** DM Sans 400/500. Use for explanations.
- **Labels:** DM Sans 700 with generous letter spacing.
- **Code:** a neutral monospace only when the post is about open source or hosted execution.

## Mark

The orange bean is Omo's small character cue. Keep it simple: orange body, pine outline, two dot eyes, small smile. It can guide a path, sit beside an artifact, or appear in a corner. Do not turn it into a busy mascot character.

## Layout rules

- Square social canvas: 1080 x 1080.
- Keep the frame inset by about 34 px.
- Keep the headline to two short lines when possible.
- Keep one idea per post.
- Use real text overlays for all important words. Do not ask an image model to render long copy.
- Use illustrations as evidence of the idea, not as decoration.
- Leave breathing room. Omo should look considered, not crowded.

## Do not use

- Neon gradients.
- Generic robot faces.
- Fake terminal copy.
- Dense dashboards with unreadable microcopy.
- Official Minecraft logos or game UI.
- Orange backgrounds for every post.
- Claims that imply every workflow is already live or proven when it is not.

## The first five posts

1. **Manifesto:** Buy the result. Not another subscription.
2. **How it works:** Pick a workflow. Add your inputs.
3. **Open source:** Free to download. Pay to host the run.
4. **Marketplace:** One marketplace. Many useful outcomes.
5. **Brand statement:** One prompt in. Finished work out.
