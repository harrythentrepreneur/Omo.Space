### 01-before-you-pay
Before you pay for another AI tool, check the result, inputs, output format, failure behavior, and ownership. A clear workflow should make all five visible before you run it.

### 02-pay-per-run-math
A subscription is right for a tool you use as a daily system. Pay per run is often better for a bounded job you need occasionally. This example uses Omo helpers priced at $0.10 per run.

### 03-comments-to-decisions
Do not turn a pile of comments into a confident summary. Clean the data, group the actual problems, keep supporting quotes, count carefully, and convert each theme into a specific action.
